Потрібно змінити пароль від 1С?
	Раз в місяць для безпеки кожному користувачу потрібно оновлювати пароль для роботи з сервером 1С.
	Повідомлення про це матиме зміст: "Срок действия пароля для учетной записи этого пользователя истёк. Чтобы войти в систему, необходимо сменить пароль."

	Для цього користувачу необхідно зайти на той же сайт https://ts01.sota.local/rdweb/Pages/, де завантажувався ярлик "1С Предприятие":

	ввести логін у вигляді sota\ **Логін** та існуючий пароль.
	Потім відкриється сторінка, щоб квазати новий пароль.

	P.S. на помилку по типу, як на скріншоті не звертаємо увагу, вибираєте "Дополнительные" і "Перейти на сайт..."

	Детальна інструкція на hub.sota.ua https://hub.sota.ua/view_doc.html?mode=doc_type&custom_web_template_id=6277935878286220858&doc_id=7093063372371288358&code=self_it_doc
