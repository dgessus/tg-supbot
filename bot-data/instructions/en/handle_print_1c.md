Does the printer not print from 1C?
1. Completely exit 1C by right-clicking on the RDP icon, as in the screenshot, and clear the cache using the corresponding shortcut on the desktop
2. Log in to 1C again and check printing
3. **If the printer is still not there**, check in the control panel whether your printer is displayed in the system
To do this, go to the control panel ---> select the item *"Hardware and Sound*" (The view from the top right should be in the position *"Category"*) ---> *Devices and Printers* and check if your printer is there. If it is not there, click the *"Add a printer"* button, select your printer and follow the instructions.
If the printer could not be found, check its connection to the network and the Internet. If the connection is available, create a ticket using the button below and attach your AnyDesk code
4. **If the printer is displayed in the system, but does not print:**
In the *"Devices and Printers"* tab, right-click on your printer and go to the *"Printer Settings"* menu and click on the test print button at the bottom of the window that opens. If the printer does not print, remove it by right-clicking on it, selecting *"Remove device"* and following the instructions in point 1

If none of the above helped, click on the "🎟 Create a ticket" button under this message
