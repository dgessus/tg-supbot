Need to change your 1C password?
Once a month, for security reasons, each user needs to update their password for working with the 1C server.
The message about this will contain the following content: "The password for this user's account has expired. To log in, you must change your password."

To do this, the user needs to go to the same site https://ts01.sota.local/rdweb/Pages/ where the "1C Enterprise" shortcut was downloaded:

enter the login in the form sota\ **Login** and the existing password.

Then a page will open to enter a new password.

P.S. If you do not pay attention to the error type, as in the screenshot, select "Additional" and "Go to the site..."

Detailed instructions on hub.sota.ua https://hub.sota.ua/view_doc.html?mode=doc_type&custom_web_template_id=6277935878286220858&doc_id=7093063372371288358&code=self_it_doc
