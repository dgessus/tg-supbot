-- How to install:
1. Paste all contents of .zip file somewhere safe.
2. Configure the config.json as shown in config-template.json : without the config.json file bot will not work.
3. Configure the users.json as shown in users-template.json for setting up user permissions.
4. Create .venv (python -m venv .venv)
5. Install all required libs (python -m pip install -r req.txt)
6. Run the main.py
7. OPTIONAL: make main.py a daemon or a service (if it runs on windows). Google is your way to go, if you don't know how to do it.
